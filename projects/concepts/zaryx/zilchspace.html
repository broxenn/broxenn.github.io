0-/0/the zilchspace/0/-0

-/-what is the zilchspace?-/-

the zilchspace is a downloadable toolkit or suite in the standard zaryx installation medium for rebuilding the system with config.hjson. there are 2 ways to set it up, but they both share the same way of things.

-through the iso-

the iso already includes the entire zilchspace suite ready to go. no setup required.

-through another live system iso-

this is much more extensive, but not really a hassle. you can usually do this on any system, but gentoo livecd, exherbo, or any arch based live environment is most recommended. first, fetch the toolkit from the official zaryx-zilchspace repository in the cloned directory, run ./zilchspace install. this installs needed things for the system harvesting. if it doesn't fail, you are ready and set up.

-/-Starting zilchspace-/-

after it is set up, run ./zilchspace rebuild. This starts the rebuild process the build process can be seen in the main zaryx doc.
